    How the tiles work

    Every move becomes a new exact value.

    Fractions are preserved rather than rounded. For example, combining 8 and 3 with division creates an exact 8/3 tile, which can then be used in the next operation. Undo restores the previous set of tiles and Reset Puzzle returns to the original four numbers.
